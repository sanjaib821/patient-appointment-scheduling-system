Patient Appointment Scheduling System

Project Description

The Patient Appointment Scheduling System is a web-based application developed to simplify and automate the process of booking and managing medical appointments in hospitals and clinics.

Features

- Book new patient appointments
- View scheduled appointments
- Update appointment details
- Delete appointment records
- Store patient information in a database
- Admin appointment dashboard

Technologies Used

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- phpMyAdmin

Database

Database Name: "patient_scheduler"

Table Name: "appointments"

Project Modules

1. Appointment Booking Module
2. Appointment Management Module
3. Update/Delete Module
4. Database Module
5. Admin Dashboard Module

Project Objective

To reduce manual work, minimize scheduling errors, and improve the efficiency of patient appointment management.
